# 为什么需要它：
#   「把 5~12 位数字全换成 <number>」这种规则会顺手把错误码一起抹掉
#   （0x8009030e / 0xC0000005 / 文号 3850223 / 日期 20261025），
#   而错误原文恰恰是词条最值钱的部分。所以真实敏感值必须**逐个列出来**。
#
# 格式：每行 `类别<TAB>值`，`#` 开头是注释。纯值（无 TAB）按 other 处理。
# 类别 → 占位符：
#   group  → <qq-group>
#   uin    → <qq-uin>
#   dy     → <douyin-account>
#   name   → <name>
#   host   → <host>
#   other  → <value>
#
