# 新词条模板 —— 复制到本目录下改名，填完跑 node scripts/build-error-dict.mjs
#
# 三条硬规矩：
#   ① 错误原文从日志**复制**，不要回忆、不要翻译、不要省略
#   ② 根因查不出就写 `未查明（已排除 X、Y）`，不要写 TODO / 待补 / 占位
#   ③ 证据要能回溯：文件+行号 / 实测数据 / 上游 issue 编号，三选一
#
# 一块「- 字段:」的值如果换行，续行缩进 4 个空格。

## ERR-<CLASS>-<NNN> | <一句话标题，写现象不写结论>

- 症状: <你看到的现象。这是别人检索的入口，写得像人话>
- 错误原文: `<从日志逐字复制的报错>`
- 触发条件: <什么前提下会撞。用来判断"我是否也在同样前提里">
- 根因: <机制。查不出写：未查明（已排除 A、B）>
- 影响: <选填。坏了什么范围>
- 解决: <实际做了什么，别人能照抄。写清为什么这么改>
- 证据: <文件+行号 / 实测数据 / 上游 issue 号>
- 回滚点: <改坏了怎么退回去。没有也要写「无」>
- 防护: <下次怎么避免；如果解法本身有代价，写在这里>
- 关联: <选填。相关条目 ID，如 ERR-ENV-003>
